Rustler Recon

Rustler Recon is a reconnaissance assistant for security teams, admins and developers. It shows what a stranger can see of your website, API or server. That includes domain data, certificates, open ports, pages, interfaces and technologies, and it uses no exploits, no vulnerability payloads and no state-changing requests.

Every result is an observation or a review candidate, a hint for a human to verify and never a claimed vulnerability. It runs on your Windows machine, keeps its results in a local folder and is made for systems you own or are explicitly authorized to test.

travel_explore

Public Sources & Domain

Reads robots.txt and sitemap.xml, spots visible .git folders and collects DNS, WHOIS, ASN, Wayback and public email-pattern data. Public-source modules query third-party providers, and the Google dork builder only prepares queries without sending them.

lan

Network Inventory

Checks common TCP ports or your own port list, reads certificates, protocol versions and cipher strength, finds subdomains from a wordlist and through certificate transparency, and detects virtual hosts.

language

Web Reconnaissance

A scope-bound crawler, wordlist-based directory discovery, checks of CSP, HSTS, CORS and cookie flags, technology and CMS detection, a JavaScript inventory that keeps secrets only as redacted fingerprints, and page screenshots.

api

APIs & Cloud

Reads OpenAPI and Swagger specifications, checks GraphQL introspection with fixed, non-mutating queries, maps SOAP services, finds API routes and hidden GET parameters, and lists cloud storage candidates read-only.

folder_special

Projects & Targets

Import a scope with one target per line, expand wildcards such as *.example.com through certificate transparency and scan up to five targets in parallel, with a status for each target.

hub

Attack Surface & Reports

Rustler Dash merges all results into assets, services, endpoints and review signals. Search and filter them, mark each candidate as open, reviewed or false positive, and create an HTML report with one click.

fact_check

Honest Results

Every run reports a clear state, which is complete, partial (a provider was down), incomplete evidence, skipped or failed. Missing results are marked as incomplete instead of being shown as “nothing found”.

swap_horiz

Proxy & HTTP History

Route traffic through Burp or any HTTP(S), SOCKS5 or SOCKS5H proxy, with bypass lists and a built-in proxy test. The HTTP history keeps redacted metadata only, with no response text and no query values.

shield_lock

Local & Data-Minimal

Rustler runs on your machine and writes its results to a folder you choose. Authorization headers, cookie values and detected secrets are redacted before they are saved. Rustler sends no telemetry to KintsuKai. Some modules query public third-party sources such as certificate transparency logs or the Wayback Machine.

How It Works

1

Enter a target

Type a domain, IP or URL, or import many targets at once. Use only targets you own or are allowed to test.

2

Pick a profile

Guided Safe Recon for a safe start, Extended Recon for more depth, or your own module selection.

3

Start the scan

Rustler collects observations such as DNS, certificates, open ports, pages and APIs. Progress streams live in the terminal.

4

Read the results

Review them in Rustler Dash or the HTML report, sorted and marked as “to review”, never as confirmed vulnerabilities.

A Clear Product Boundary

Rustler Recon observes and inventories. It does not attack, and it never claims that a vulnerability is confirmed.

Rustler Recon does

  • check_circleAuthorized discovery and inventory requests
  • check_circleGET, HEAD and OPTIONS observation, with GraphQL limited to fixed queries
  • check_circleDNS, TLS, port, web, API and cloud inventory
  • check_circleReview signals with traceable provenance
  • check_circleRedacted, data-minimal result storage

Rustler Recon does not

  • cancelNo exploits or vulnerability payloads
  • cancelNo state-changing requests such as PUT, PATCH, DELETE or mutations
  • cancelNo login or password checking
  • cancelNo callback or OAST tests
  • cancelNo “vulnerability confirmed” claims
gavel

Authorized use only

Rustler sends real, visible requests to the target, and the target can see them in its logs. Scan only your own systems or systems you have explicit written permission to test.

CVSSense Pro

CVSSense Pro is the professional edition of CVSSense for security teams. It turns every finding into a traceable CVSS v4.0 assessment: guided for every analyst, precise for every expert, and reviewed before it leaves your team.

Installed on your own server in minutes. No cloud, no telemetry and no internet connection required. Your vulnerability data stays in house.

How It Works

1

Install

One Docker image and one data volume. Start it and read the one-time setup code from the log.

2

Set Up

A browser wizard asks for your license, address, HTTPS mode and the first administrator account.

3

Assess

Invite your team, connect single sign-on and start scoring. Backups and policies live in Settings.
